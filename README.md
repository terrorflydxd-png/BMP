# ЦехУчёт — серверный прототип

Учёт задач механического цеха с общими данными на сервере. Несколько человек могут работать одновременно с одного адреса: задачи, станки и журнал перемещений хранятся в базе, а не в браузере.

> **Нужен доступ из интернета?** Инструкция по бесплатному запуску на Render + Neon — в файле [README-DEPLOY.md](README-DEPLOY.md).

## Что умеет

- 8 станков (фрезерные, токарные, эрозия, слесарный пост), у каждого статус: работает, наладка, свободен, ремонт.
- 12 демо-задач: детали и общие задачи, нормы времени, выработка, подзадачи, приоритеты.
- Вход по PIN-коду, роли: директор, мастер, рабочий.
- **Директор и мастер имеют одинаковые права:** ставят и редактируют задачи, меняют исполнителя и приоритет, перемещают любые задачи, меняют статус станка, смотрят и выгружают историю.
- **Рабочий** видит свои задачи, отмечает выработку и может переместить свою задачу на любой доступный станок.
- **Каждое перемещение сохраняется навсегда:** кто, когда, откуда, куда, причина и комментарий. Станок в ремонте выбрать нельзя.
- История перемещений с фильтрами по станку и причине, выгрузка в CSV для руководителей.
- Расчёт стоимости по ставке **25 BYN за нормо-час**.

## Быстрый запуск

Нужен Python 3.10 или новее.

### Windows

Дважды щёлкните `run.bat` или выполните в папке проекта:

```bat
python -m pip install -r requirements.txt
python app.py
```

### macOS / Linux

```bash
chmod +x start.sh
./start.sh
```

или вручную:

```bash
python3 -m pip install -r requirements.txt
python3 app.py
```

После запуска откройте в браузере: **http://127.0.0.1:8000**

Сервер слушает только локальный адрес. Порт можно изменить переменной `PORT`, например `PORT=8080 python app.py`.

| Андрей Соколов — директор | `1111` |
| Сергей Ковалёв — мастер смены | `2222` |
| Игорь Петров — токарь | `3101` |
| Роман Зайцев — токарь | `3108` |

Остальные рабочие: PIN с `3102` по `3112`. На экране входа эти же карточки можно нажать мышью — вводить PIN не обязательно.

## Как проверить сценарий

1. Войдите как рабочий `3101`, откройте свою задачу «Втулка-04».
2. Нажмите «Переместить», выберите другой станок и причину, добавьте комментарий.
3. После перемещения откройте «История»: сверху будет запись с вашим именем, старым и новым станком, причиной и комментарием.
4. Войдите как мастер `2222` или директор `1111`: доступны те же разделы «Задачи», «Люди», «История», кнопка «Поставить задачу» и перемещение любой задачи.
5. Попробуйте переместить чужую задачу под рабочим — сервер откажет: рабочий может двигать только свои задачи.

## Данные

- Локально база создаётся автоматически при первом запуске в папке `data/ceh.db`. В облаке используется PostgreSQL из переменной `DATABASE_URL`.
- Демо-данные можно вернуть через «Настройки» → «Сбросить демо-данные» (только директор и мастер).
- Чтобы начать полностью с нуля, остановите сервер и удалите файл `data/ceh.db` — при следующем запуске он создастся заново.
- Журнал перемещений доступен только для чтения: в интерфейсе и API нет удаления записей.

## Структура

```
app.py              сервер: API, роли, SQLite, расчёты
static/index.html   оболочка страницы
static/styles.css   оформление и адаптивная вёрстка
static/app.js       интерфейс, формы, история
requirements.txt    зависимости
start.sh / run.bat  запуск на macOS/Linux и Windows
```

## Технические детали

- FastAPI + SQLite локально или PostgreSQL в облаке, сессия в HttpOnly-cookie на 7 дней.
- Ставка и нормы времени считаются на сервере; клиент только отображает результат.
- Текущий станок задачи всегда совпадает с последней записью журнала.
- API-документация: http://127.0.0.1:8000/api/docs
